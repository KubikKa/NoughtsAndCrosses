# NoughtsAndCrosses
Game Made In Python

Hi! This is a game called 'Noughts and crosses'.

> Those are the rules 📖:
1. The first move is made by the player who gets the crosses. You need to select a square (1-9) where you want to place the cross.
2. Next, the noughts player chooses another square to place the nought in it.
3. Both players continue to take turns to place their symbol in a square aiming to get three (X) or (O) in a row to win.
   Remember, you can not place your symbol in a square which is already occupied!
4. The three in a row can be in a horizontal, vertical or diagonal line.
